# 要件定義（簡易）

## 目的
USDJPY の1tickデータを用いたバックテスト用デスクトップアプリを段階的に開発する。

## 対象データ
- データソース: Dukascopy Datafeed
- 取得URL例:
  - https://datafeed.dukascopy.com/datafeed/USDJPY/2022/03/04/20h_ticks.bi5
- URL規則（メモ）:
  - https://datafeed.dukascopy.com/datafeed/{PAIR}/{YYYY}/{MM}/{DD}/{HH}h_ticks.bi5
  - 1時間ごとに1ファイル
  - 00h〜23h の24ファイル/日
  - URLの月は0始まり（00〜11）
- 保存形式:
  - 生データ: .bi5（圧縮バイナリ）
  - 変換データ: .csv（必要に応じて作成）
- 保存フォルダ:
  - data/bi5（生データ。JST日付で整理）
  - data/csv（変換後データ。JST日付で1日1ファイル）
- アプリの時刻基準: JST
- 保存フォルダの月表記: 1〜12（URLの0始まりとは別で管理）
- 0バイトのファイルは削除し、再取得扱いにする
- 土日を除外する設定を用意する（初期オン）
- 除外の目安（JST）:
  - 冬時間: 土曜7時〜月曜7時
  - 夏時間: 土曜6時〜月曜6時

## 段階的実装計画
### STEP1: 期間指定とティックデータ取得
- UIで開始日〜終了日をカレンダーで指定
- 指定期間に該当する時間ファイルを自動DL
- data/bi5 に保存
- 既に存在するファイルは再DLしない（キャッシュ）
- data/csv にJST日付で1日1ファイルのCSVを生成
- 欠損があっても1時間分でもデータがあればCSVを生成する
- 土日を除外するチェックを用意し、オン時は対象外の時間はDLしない
- まだチャート表示やバックテストは行わない

### STEP2: ティック/足チャート表示
- 取得済みデータを読み込み、UI上にティック/足チャートを表示
- 開始日・終了日（JST）の指定と表示ボタンを用意する
- 表示ボタンの隣に中止ボタンを用意し、表示計算中の中断を可能にする
- パラメータ入力エリアは横並び中心に配置し、チャートの縦表示領域を優先する
- 拡大縮小と横移動ができ、表示範囲に合わせて縦軸を自動フィット
- 縦軸（右端）に価格、横軸（下段）に時刻ラベルを表示
- 横軸は「時間ベース / 本数ベース」を切り替え可能（初期は時間ベース）
- 足の種類を切り替え可能（1/3/5/15/30分、1/2/4時間、日足）
- ジグザグ・レンジ補助線・水平線の表示を切り替え可能
- 表示のみ（売買ロジックは未実装）

### STEP3: バックテスト
- 戦略を切り替え可能
  - スパイク条件
  - 水平線戻り条件
- 戦略の初期選択は「水平線戻り」
- スパイク条件（従来）
  - スパイク時間（ミリ秒）
  - スパイク幅（ピップス）
  - 最小戻し率（％）
  - スプレッド（ピップス、初期1）
  - 損切幅（ピップス、初期5）
  - 利確幅（ピップス、初期5）
  - 時間経過クローズ（分、初期0）
    - 0は無効
    - 0より大きい値のとき、損切/利確未到達でも指定分経過時点で強制クローズ
    - 強制クローズ価格は、その時点が属する1分足の終値を使用
- 水平線/補助線の条件
  - ジグザグ幅（ピップス）
  - ブレイク幅（ピップス）
  - 最小本数
  - レンジ本数
- 水平線戻り条件
  - 抜け幅（pp、初期5）
  - 平均ティック/分 上限（初期100）
  - 平均ティック/分 下限（初期0）
  - 最小秒数（初期5）
  - 対象秒数（初期60）
  - 滞在判定位置（％、初期50）
    - 0=水平線、100=抜け後の極値
  - 優勢滞在率（％、初期50）
    - 判定期間内で、有利側の滞在時間比率がこの値以上のときのみエントリー
  - 有利平均幅比率（％、初期100）
    - 判定期間内の上げ/下げティックの平均幅を比較し、有利側平均幅がこの比率以上のときのみエントリー
  - 待機本数（初期3）
  - 対象線（水平線/補助線/両方）
- チャート表示期間に対するバックテスト成績を表示
- 「損益」タブで損益の折れ線グラフを表示
- 水平線戻りかつ対象線が両方の場合、水平線/補助線の内訳を損益タブに表示
- 同一表示期間での再計算時は、読み込み済みデータと下準備（足・線など）を再利用して高速化する

## 追加の初期設定
- 時間帯除外は初期オン
- 初期の除外対象は05〜10時（午前）
