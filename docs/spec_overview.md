# 全体仕様

## 1. 目的
本アプリは、`USDJPY` のティックデータを使って、過去期間の売買シミュレーションを行うデスクトップアプリです。  
主な用途は以下です。

- 期間指定でのデータ取得
- チャート確認
- 複数戦略の検証
- 損益の比較
- 結果の保存と再読込

## 2. 対象データ
- 取得元: Dukascopy Datafeed
- 取得単位: 1時間ごとの `bi5` ファイル
- 時刻基準: 日本時間（JST）
- 週末除外:
  - 有効時は市場休止時間帯を取得対象外にする
  - ニューヨーク夏時間は土曜6時〜月曜6時（JST）
  - それ以外は土曜7時〜月曜7時（JST）

## 3. 主なフォルダ構成
- `data/bi5/USDJPY/...`
  - 取得した元データ
- `data/csv/USDJPY/...`
  - 日次に変換したティックCSV
- `results/`
  - 実行結果一式
- `ui_state.json`
  - 画面状態の保存ファイル

## 4. 処理フロー
1. ダウンロードタブで年月を指定し、`bi5` を取得する。  
2. 同時に日次のティックCSVを作成する。  
3. パラメータタブで条件を設定して実行する。  
4. 実行結果をチャートタブ・損益タブで確認する。  
5. 結果は `results` に保存され、後で再読込できる。

## 5. 実行モード
- 単月実行:
  - 現在の表示期間で1回実行
- 一括実行:
  - 指定した開始年月〜終了年月を月単位で連続実行
  - 一括中はチャート描画を行わず、計算を優先
  - 最後に合算損益、年別・月別集計を表示

## 6. 戦略の構成
選択できる戦略は以下の5種類です。

- 秒逆張り
- 勢い追随
- 水平線戻り
- 水平線手前
- スパイク

複数戦略を同時に有効化できます。  
同時利用時は連続点灯条件などの共通制御が適用されます。

## 7. 損益表示
損益タブでは以下を扱います。

- 累積損益グラフ
- 年別損益棒グラフ
- 月別損益棒グラフ
- 勝率、連勝連敗、最大ドローダウン
- ロング/ショート内訳
- 時間経過クローズ件数・割合・収支

## 8. 保存と再利用
実行後は `results` に保存され、次回以降に再利用できます。

- 設定ファイル（JSON）
- 取引一覧CSV
- ナンピン詳細CSV
- index.csv（一覧用）

同一設定判定は、実際に使われる項目だけで作る「判定用パラメータ」で行います。  
未使用項目は同一判定に影響しない設計です。
