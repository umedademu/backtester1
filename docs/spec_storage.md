# 保存・読込仕様

## 1. 保存先
- ルート: `results`
- 通貨: `USDJPY` 固定
- 戦略フォルダ名:
  - 有効戦略の連結文字列（例: `水平線+勢い追随+秒逆張り`）
- 設定フォルダ名:
  - `設定_<設定ID>`

例:

`results/USDJPY/水平線手前/設定_XXXXXXXX/`

## 2. 設定IDの作成

## 2.1 基本
- 関数 `build_settings_id_params` で判定用の値を作る。
- 判定用の値を正規化してJSON化し、SHA1先頭8文字を設定IDにする。

## 2.2 判定の考え方
- 「実際に使う項目」のみ判定対象にする。
- 無効な戦略の個別項目は判定に入れない。
- OFFの条件（例: 速度フィルターOFF）は中身の値を判定から外す。
- 共通優先がONの項目は、個別値ではなく共通値で判定する。
- 水平線手前のみ有効でも、線条件と手前条件は判定対象に入る。

この設計により、見た目だけ違っても実行に影響しない差分では設定IDが変わらない。

## 3. 重複期間の扱い
- 実行時に `重複期間` を `スキップ/上書き` から選ぶ。
- 判定対象:
  - 同じ戦略フォルダ
  - 同じ設定IDフォルダ
  - 同じ月（`取引一覧.csv` の `out時刻` の年月）
- `スキップ`:
  - 対象月が既にあれば実行を飛ばす。
- `上書き`:
  - 対象月の既存行を除去して新しい結果で置換する。

## 4. 保存ファイル

## 4.1 設定ファイル
ファイル: `設定.json`

主な項目:
- 通貨
- 戦略
- 設定ID
- 保存日時
- パラメータ
- 判定用パラメータ
- 画面設定

## 4.2 取引一覧
ファイル: `取引一覧.csv`

列:
- 開始日
- 終了日
- 実行ID
- 取引ID
- in時刻
- out時刻
- 方向
- in価格
- out価格
- ロット合計
- 損益
- 累計損益
- in理由
- out理由
- ライン種別
- ナンピン回数
- 平均in価格

## 4.3 ナンピン詳細
ファイル: `ナンピン詳細.csv`

列:
- 開始日
- 終了日
- 実行ID
- 取引ID
- 段階
- 種別
- in時刻
- in価格
- ロット

## 4.4 一覧
ファイル: `results/index.csv`

列:
- 実行時刻
- 通貨
- 戦略
- 設定ID
- 保存先
- 開始日
- 終了日
- 取引数
- 勝ち
- 負け
- 合計損益
- 最大DD

同一の `通貨 + 戦略 + 設定ID` は1行に保ち、最新内容で更新する。

## 5. 読込仕様

## 5.1 損益タブでの読込
- `index.csv` を逆順に読んで候補を作る。
- `最小損益` と `絞り込み` で候補を絞れる。
- 候補行から `保存先` を辿って `取引一覧.csv` を読込む。
- 表示時は以下も更新する。
  - 損益グラフ
  - 年別損益
  - 月別損益
  - 取引統計
- 年別棒グラフの年選択時は、月別棒グラフを選択年の `1月〜12月` の12本表示に切り替える（データがない月は0で表示）。

## 5.2 チャートタブでの読込
- 保存結果を選び、月を選んで `表示` すると、その月の取引だけを重ね表示する。
- 設定ファイルがあれば、以下を保存時の内容で復元して表示する。
  - 移動平均設定（ON/OFF、単位、期間）
  - 水平線条件（ジグザグ幅、ブレイク幅）
  - レンジ補助線条件（レンジ本数）
  - 線表示設定（ジグザグ、水平線、レンジ補助線）
- これにより、保存結果表示時のチャートでも水平線系の再現表示ができる。

## 5.3 設定反映
- 損益タブの `設定反映` は、選択した保存結果の `設定.json` から
  - パラメータ
  - 画面設定
  を現在の画面に反映する。

## 5.4 ブックマーク
- `戦略 + 設定ID` をキーに保存結果をブックマークできる。
- ブックマーク状態は `ui_state.json` に保存される。

## 6. 画面状態ファイル
- ファイル: `ui_state.json`
- バックアップ: `ui_state.json.bak`
- 保存内容:
  - 日付、タブ条件、戦略条件、決済条件、ナンピン条件、フィルター条件、ブックマーク等の画面状態全般
