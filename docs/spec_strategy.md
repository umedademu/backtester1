# 戦略・判定仕様

## 1. 前処理
- 入力はティック列（時刻、Bid価格）。
- 必要に応じて足データを生成する（表示足の間隔）。
- 水平線系戦略では、以下を使って候補線を作る。
  - ジグザグ由来の支持線・抵抗線
  - レンジ補助線
- 対象線は `水平線` `補助線` `両方` から選択。

### 1.1 ジグザグ生成ルール
- 反転確定の前提条件は「最小幅（ジグザグ幅）」到達。
- 最小本数条件は持たない（値幅条件のみで反転確定）。
- 山谷を更新した同じ足では反転確定しない（次の足以降で確定判定）。
- ジグザグ点は山谷の足時刻に描画する。
- 末尾の暫定点は、直前の山谷と同じ足時刻なら追加しない。
- 未来視回避はジグザグではなく、水平線が売買判定に使える開始時刻の管理で行う。

## 2. 共通フィルター
全戦略のエントリー前に次を評価する。

- 時間帯除外
  - 指定時間はエントリーしない
- 移動平均フィルター
  - 指定期間の移動平均との乖離率を満たす場合のみ許可
- 同時保有制御
  - 同方向同時保有
  - 逆方向同時保有

## 3. 戦略別エントリー判定

## 3.1 スパイク
- 監視時間内で一定幅の急変を検出。
- 急変後に最小戻し率を満たした時点で逆方向エントリー。
- 天底フィルター有効時は、維持時間と距離条件を追加評価。

## 3.2 秒逆張り
- 一定秒数内での上下どちらかの到達幅で逆張り方向を決定。
- 停滞秒が0より大きい場合:
  - 極値更新が止まって指定秒数経過後にエントリー。
- 戻り上限が有効な場合:
  - 監視中に戻り幅が上限を超えるとシグナル破棄。
- 監視抜け撤退が有効な場合:
  - 決済時に追加の撤退条件を持つ。

## 3.3 勢い追随
- 監視時間内に一定幅へ到達した方向を追随方向とする。
- 境界位置（%）を割り込まないことを継続条件にする。
- 継続秒数到達時点で平均ティック/分の下限を満たせばエントリー。
- 上限（pp）を超える一方向進行が発生した場合は破棄。

## 3.4 水平線戻り
- 線の抜け（ブレイク）発生後、戻りを監視。
- 必須条件:
  - 抜け幅
  - 待機本数
  - 最小秒数
  - 対象秒数
  - 対象線
- 任意条件（ON/OFF可能）:
  - ティック上限
  - ティック下限
  - 滞在位置
  - 優勢滞在率
  - 平均幅比率
  - 速度比率
  - 有利1ティック幅下限
- 比率条件は `両方`（AND） / `どちらか`（OR）を選択可能。

## 3.5 水平線手前
- 候補線ごとにエントリー水準を作る。
  - 支持線: `線価格 + 手前幅`
  - 抵抗線: `線価格 - 手前幅`
- 価格がエントリー水準を通過した時点でエントリー候補。
- 速度フィルター有効時:
  - 判定秒数ぶん遡って値動き幅を算出し、必要接近幅以上なら通過。
  - ロング候補は「直近からの下落幅」、ショート候補は「直近からの上昇幅」を使う。
- 手前幅はマイナス指定可能（線を越えてからのエントリーも可能）。

## 4. 連続点灯条件
- 有効時は、各戦略のシグナルをそのまま使わず、連続条件を満たしたものだけ通す。
- 評価項目:
  - 正方向幅
  - 逆方向幅
  - 連続回数
  - 監視時間
  - 戦略ごとの見送り対象
  - 戦略ごとのカウント対象
  - 戦略ごとの最終きっかけ対象

## 5. 建値と損益の扱い
- ロング建値: `Bid + スプレッド`
- ショート建値: `Bid`
- 損益はピップスで集計し、ロット合計を反映する。

## 6. 決済仕様
決済理由は主に以下。

- 損切
- 利確
- 時間（時間経過クローズ）
- 急伸利確
- 抜け撤退（監視抜け撤退）
- 終了（データ末尾）

### 6.1 固定決済
- ON:
  - 損切・利確は設定価格で約定
- OFF:
  - 到達時点の実勢価格（Bid/Ask）で約定
- 時間クローズは固定決済設定に関係なく実勢価格で約定

### 6.2 時間経過クローズの起点
- 初回
  - 最初の建玉時刻から秒数を数える
- 最終
  - 最後の建玉時刻から秒数を数える

## 7. ナンピン仕様
- 初回建玉ON/OFFを持つ。
- 段階1〜5を個別に有効化可能（幅・ロット設定）。
- 追加建玉は逆行幅の累積到達で実行。
- 平均建値はロット加重平均。
- 利確判定は平均建値基準。
- 損切判定は最後の建玉価格基準。
- 追加建玉が完了するまで損切を待機する設計。

## 8. 集計仕様
- 取引数、勝ち、負け、引き分け
- 勝率
- 最大連勝、最大連敗
- 合計損益、平均損益
- 最大ドローダウン
- ロング/ショート内訳
- 時間経過クローズ件数、割合、その収支
