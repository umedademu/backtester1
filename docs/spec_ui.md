# 画面仕様

## 1. タブ構成
アプリの上位タブは以下の4つです。

- パラメータ
- チャート
- ダウンロード
- 損益

## 2. パラメータタブ

### 2.1 共通エリア
- 実行関連
  - `実行`
  - `中止`
  - `重複期間`（スキップ / 上書き）
  - `一括実行`
- 表示期間
  - 開始年月
  - 終了年月
  - 前 / 次 の月移動
- 決済条件（共通）
  - スプレッド
  - 損切幅
  - 利確幅
  - 時間経過（秒）
  - 時間計測起点（初回 / 最終）
  - 急伸利確（最低幅・時間・幅）
  - 損切/利確を固定決済
  - 各項目ごとに「共通優先」の切替
- ナンピン条件（共通）
  - 初回エントリー有効
  - 段階1〜5（有効、幅、ロット）
  - 「共通優先」の切替
- 共通フィルター
  - 移動平均フィルター（期間、単位、乖離率）
  - 時間帯除外（時間帯設定ダイアログ）
  - 同方向同時保有
  - 逆方向同時保有
- 連続点灯条件
  - ON/OFF
  - 正方向幅
  - 逆方向幅
  - 連続回数
  - 監視時間
  - 見送り対象、カウント対象、最終きっかけ（戦略ごと）
- 保存結果（最新）
  - 保存先フォルダ
  - 設定ファイル
  - 取引一覧
  - ナンピン詳細
  - 一覧（index）
  - 各項目に `開く` ボタン

### 2.2 戦略タブ
戦略タブは5つあります。

- 秒逆張り
- 勢い追随
- 水平線戻り
- 水平線手前
- スパイク

各戦略タブに共通して以下を持ちます。

- 戦略ON/OFF
- 決済条件（個別）
- ナンピン条件（個別）

### 2.3 主要な初期値
| 区分 | 項目 | 初期値 |
|---|---|---|
| 戦略ON/OFF | 水平線戻り | ON |
| 戦略ON/OFF | それ以外 | OFF |
| 共通 | スプレッド | 1.0 |
| 共通 | 損切幅 / 利確幅 | 10.0 / 10.0 |
| 共通 | 時間経過 | 0秒 |
| 共通 | 時間計測起点 | 最終 |
| 共通 | 急伸利確 | 5pp / 2000ms / 5pp |
| 共通 | 各共通優先 | ON |
| 共通 | 時間帯除外 | ON（初期は05〜10時） |
| 共通 | 移動平均フィルター | ON（200分、乖離0.01%） |
| 連続点灯 | ON/OFF | ON |
| 連続点灯 | 正方向 / 逆方向 / 回数 / 監視時間 | 10pp / 5pp / 3 / 240分 |
| 水平線手前 | 手前幅 | 3pp |
| 水平線手前 | 速度フィルター | ON（2秒で10pp） |
| 水平線手前 | 対象線 | 水平線 |

## 3. チャートタブ

### 3.1 上部の保存結果エリア
- 保存結果の選択
- 更新、前へ、次へ
- 月の選択
- 表示
- ブックマーク（★）

### 3.2 表示操作
- 横軸: 時間 / 本数
- 表示: ティック / 足
- 表示足: 1分、3分、5分、15分、30分、1時間、2時間、4時間、日足
- 線表示: ジグザグ、水平線、レンジ補助線
- チャート非表示
- 取引ナビ: 取引番号、移動、前へ、次へ

## 4. ダウンロードタブ
- 取得期間（開始年月、終了年月）
- 土日除外チェック
- ダウンロード
- キャンセル
- 実行ログ表示

## 5. 損益タブ

### 5.1 保存結果操作
- 保存結果の選択
- 表示、更新、前へ、次へ
- 設定反映
- ブックマーク（★）
- 最小損益入力
- 絞り込みボタン

### 5.2 表示要素
- 文字情報（取引数、勝率、連勝連敗、合計損益、最大ドローダウンなど）
- 時間経過クローズの件数・割合・収支
- 損益グラフ
- 年別損益
- 月別損益

年別・月別グラフはクリックで期間フィルターとして動作します。
- 年別棒グラフで年をクリックすると、損益グラフはその年で絞り込み、月別棒グラフはその年の `1月〜12月` の12本表示に切り替わります。
- 月別棒グラフで月をクリックすると、損益グラフはその月で絞り込みます。

## 6. 終了時の確認
- シミュレート実行中にウィンドウ右上の `×` を押した場合は、確認ダイアログを表示する。
- `いいえ` の場合は終了せず、そのまま実行を継続する。
- `はい` の場合は実行中処理を中止して終了する。
